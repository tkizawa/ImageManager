# WoodStream ImageManager (画像・写真管理アプリ)

WoodStream ImageManager は、指定したフォルダ内の画像ファイルを高速かつ簡単に閲覧・管理するための Windows 向けデスクトップアプリケーションです。
.NET 10 と WinUI 3 (Windows App SDK)、MVVM アーキテクチャを用いて構築されています。

## 主な機能

* **フォルダナビゲーション（ツリー / お気に入り / 履歴 / ライブラリ）**: 画面左側のタブ付きナビゲーションペインから簡単にフォルダへアクセスできます。
  * **ツリー**: ドライブやフォルダを階層的にたどって画像ファイルを読み込みます。「フォルダを開く...」ボタンからの選択も可能です。
  * **お気に入り**: よく使うフォルダを「お気に入り」に登録し、ワンクリックで素早くアクセスできます。
  * **履歴**: 直近で開いたフォルダ（最大20件）が自動的に記録され、いつでも再アクセスできます。右クリックメニューから個別に削除も可能です。
  * **ライブラリ**: 複数のフォルダを任意の名前のグループ（ライブラリ）にまとめて管理できます。「新規ライブラリ」から作成し、フォルダを追加できます。
* **サムネイル表示とズーム・並び替え**: 選択したフォルダ内の画像がサムネイル形式で一覧表示されます。
  * **並び替え**: 「更新日時」「撮影日時」「レート」順、昇順／降順でソート切り替えが可能。
  * **ズーム**: `Ctrl + マウスホイール` でサムネイルサイズの拡大・縮小が可能。
  * **レートバッジ**: レートが設定されている写真には左上に `★3` などのバッジを表示。
* **⭐ お気に入り・レート機能と絞り込み（フィルター）**:
  * **お気に入りフラグ**: サムネイル右上の星ボタン、右クリックメニュー、またはビュアー内での `F` キーでお気に入りを即座に切り替え。
  * **レート設定 (★1～5 / なし)**: 右ペインの星ボタン、右クリック「レートを設定」メニュー、キーボードの `0`～`5` キー（テンキー対応）で瞬時に設定・解除。複数画像の一括設定にも対応。
  * **レートフィルター**: ツールバーのドロップダウンから「★1」～「★5」「レートなし」「すべてのレート」を選択して瞬時に絞り込み表示。
  * **お気に入りとのAND条件連動**: 「お気に入りのみ」ボタンと「レートフィルター」を併用すると、**お気に入り かつ 指定レート** の両方を満たす写真のみを抽出表示。
* **📋 画像のコピー・移動・削除・クリップボード操作**:
  * **一括コピー / 移動**: ツールバーや右クリックメニューの「フォルダへコピー...」「フォルダへ移動...」から別フォルダへ一括転送。
  * **クリップボード連携**: `Ctrl + C`（コピー）、`Ctrl + X`（切り取り）、`Ctrl + V`（貼り付け）に対応。Windowsエクスプローラーとの相互コピー・貼り付けも可能。
  * **削除**: 選択した画像を `Delete` キーまたは右クリックメニューからゴミ箱へ削除。
* **画像の右クリック操作**: サムネイルを右クリックするとコンテキストメニューが表示され、以下の操作が可能です。
  * **レートを設定**: ★1～5およびレートなしを直接指定。
  * **お気に入りの切り替え**: お気に入りフラグのON/OFF。
  * **コピー / 切り取り / 貼り付け / 削除**: 画像ファイルの操作。
  * **Windowsのフォトで開く**: 標準のフォトアプリで画像を開きます。
  * **エクスプローラーで表示**: 対象のファイルを選択した状態でWindowsのエクスプローラーを開きます。
* **画像のプレビューと詳細・EXIF情報の確認**: サムネイルをクリックすると、右側のペインにプレビュー画像、星レート操作UI、および詳細プロパティが表示されます。
  * ファイル名、ファイルサイズ (Bytes)、ファイル作成日時、撮影日
  * **EXIF情報**: カメラモデル、レンズ、F値、露出時間、ISO、焦点距離（※情報が含まれる写真のみ表示）
* **別ウィンドウでの画像ビュアー**: サムネイル画像をマウスでダブルクリックすると画像ビュアーが別ウィンドウで開きます。画像ビュアーでの操作は以下の通りです。
  * 左右のカーソルキーまたはマウスのホイールで画像切り替え
  * `Ctrl` キーを押しながらマウスのホイールで画像の拡大・縮小
  * マウスのドラッグアンドドロップで画像表示の移動
  * `F` キーでお気に入りの切り替え
  * `0`～`5` キー（テンキー対応）でレートの設定・解除
  * 右クリックメニュー、または `I` キーで写真情報（ファイル名・撮影日・お気に入り・レート・EXIF等）の表示・非表示切り替え
  * `Esc` キーで閉じる
* **📷 各社 RAW 画像（CR3 / ORF / NEF / ARW / DNG / CR2 等）のフル解像度プレビューと縦横自動回転**:
  * **フル解像度プレビュー**: Canon CR3、Olympus ORF、Nikon NEF、Sony ARW などの各社RAW画像からフルサイズの最高画質プレビュー（6000x4000 等）を自動抽出して高速描画。
  * **縦横自動回転**: カメラ本体のジャイロセンサー（Exif Orientation）を自動解析し、縦撮り写真を正しい縦向きに自動回転してサムネイルおよびビュアーに表示。
* **🎨 外部プログラム連携（Photoshop / GIMP / ペイント等）**:
  * **プログラムの登録**: 「設定（歯車）」メニューの「外部プログラムの設定...」から、よく使う画像編集ソフト（Photoshop、GIMP、Affinity Photo、ペイントなど）を自由に追加・管理。
  * **外部アプリで開く**: サムネイルやビュアーの右クリックメニュー「外部プログラムで開く」から、登録したアプリを選択して瞬時に画像を渡して起動。
* **AI自動分類機能**: ヘッダーの「AI自動分類」ボタンから、画像フォルダ内の写真を主要カテゴリー（人物・風景・動物・食べ物・乗り物・建物・文書等）へ自動判定します。ONNX Runtime（DirectML GPU加速/CPU）および特徴・色調解析に対応し、カテゴリー別のサブフォルダへのコピー・移動、または属性（タグ）の付与をまとめて実行できます。
* **💾 サムネイルのキャッシュ管理と自動削除**:
  * **キャッシュの一括削除**: 「設定」メニューの「キャッシュの管理...」から現在のキャッシュ容量・ファイル数を確認し、ワンクリックで一括削除（クリーンアップ）。
  * **終了時の自動クリーンアップ**: 経過日数（7日、14日、30日、60日）または容量上限（1GB、5GB、10GB）を指定することで、アプリ終了時に条件を満たす古いキャッシュを自動削除（削除時はメッセージを表示）。
* **設定のインポート・エクスポート（バックアップ / 復元）**: お気に入り、閲覧履歴、ライブラリ、外部プログラム設定、データベースを含む設定情報をバックアップZIPファイルとしてエクスポート・インポートが可能です。
* **アプリ内操作説明（ヘルプ）**: ヘッダーの「操作説明」ボタンまたは設定メニューから、機能概要やショートカットキー一覧をいつでもダイアログで確認できます。
* **多言語対応**: OSの表示言語（日本語 / 英語）に合わせて、アプリの表記が自動的に切り替わります。
* **レイアウトのカスタマイズ**: フォルダナビゲーション、サムネイル一覧、プレビュー欄の境界線をドラッグして幅を調整できます。調整した幅は自動保存され、次回起動時にも復元されます。
* **バージョン情報の表示**: アプリ上部（タイトルバー右端）に現在のバージョンが表示されます。

## 使い方

1. **アプリの起動**
   * アプリケーションを実行して起動します。（開発環境の場合は `dotnet run` で起動可能です）
2. **画像の読み込み**
   * 画面左上の **「フォルダを開く...」** ボタンをクリックするか、画面左側の **ツリー / お気に入り / 履歴 / ライブラリ** タブから任意のフォルダを選択します。
3. **画像の閲覧と絞り込み**
   * 中央のリストに画像がサムネイル表示されます。
   * **「お気に入りのみ」** ボタンや **「レートフィルター」** ドロップダウンを使って、目的の写真を素早く絞り込めます。
4. **レートやお気に入りの設定**
   * サムネイル右上の星をクリックして「お気に入り」を登録できます。
   * 右ペインの星ボタンをクリックするか、キーボードの `0`～`5` を押して写真にレートを付けられます。
5. **設定のバックアップと復元**
   * ウィンドウ右上の **「設定」ボタン（歯車アイコン）** をクリックします。
   * **「設定のエクスポート...」** を選択すると、お気に入りや履歴、データベースをバックアップファイルに保存できます。
   * **「設定のインポート...」** を選択すると、保存したファイルから設定を復元できます。

## 開発・ビルド環境

* **OS**: Windows 10 / 11
* **フレームワーク**: .NET 10.0
* **アーキテクチャ・ライブラリ**: 
  * WinUI 3 / Windows App SDK (UIフレームワーク)
  * CommunityToolkit.Mvvm (MVVMパターンの実装)
  * MetadataExtractor (EXIF・メタデータ解析)

### 開発者向けセットアップ

リポジトリをクローンした後、以下のコマンドでビルドおよび実行が可能です。

```bash
# プロジェクトのルートディレクトリに移動
cd ImageManager

# アプリケーションの実行
dotnet run
```

### パッケージング・インストーラーの作成

プロジェクトにはビルドおよびインストーラー作成用のPowerShellスクリプトが含まれています。

* **MSIX パッケージのビルド**: `powershell .\build_msix.ps1`
* **Inno Setup インストーラーの作成**: `powershell .\build_installer.ps1`
